Assessing BIOMASS Radiometric Stability using Permanent Scatterers

p. 1Marco Manzoni, Francesco Salvaterra, Claudio Maria Prati and Stefano Tebaldini

Abstract—Monitoring the relative radiometric stability of the European Space Agency’s BIOMASS P-band synthetic aperture radar (SAR) requires separating instrumental and processing effects from temporal changes in the scene backscatter. This study investigates the use of permanent scatterers (PSs) as opportunistic references for estimating residual radiometric gains without dedicated calibration targets. The PS-based calibration (PSCal) framework combines amplitude-based scatterer selection with iterative maximum-likelihood gain estimation. Simulations assess detection and estimation performance under the limited number of acquisitions available in BIOMASS stacks, highlighting the importance of stringent selection thresholds and the dependence of estimation accuracy on scatterer abundance and signal-tonoise ratio. The approach is applied to datasets over Nairobi, Kenya, and Córdoba, Argentina. Over Nairobi, PSCal identifies an approximately 1 dB radiometric anomaly subsequently traced to a defect in radio-frequency interference mitigation, while the remaining acquisitions exhibit estimated gain variations generally within 0.1 dB. Over Córdoba, twelve acquisitions spanning two mission phases separated by approximately eight months yield residual gain variations on the order of 0.1 dB despite pronounced changes in the scene backscatter and acquisition geometry. Results were observed to be consistent with measurements from the BIOMASS Calibration Transponder (BCT) installed in New Norcia (Australia). These results demonstrate the potential of carefully selected P-band PSs to complement dedicated calibration infrastructure for relative radiometric monitoring and the detection of processing anomalies.

Index Terms—BIOMASS, Permanent Scatterers, P-Band, Radiometric Stability.

#I. INTRODUCTION

RADIOMETRIC calibration is essential for the quantitative exploitation of spaceborne synthetic aperture radar (SAR) data [1]–[4]. This requirement is particularly important for low-frequency P-band systems, such as the ESA BIOMASS mission [5], whose long wavelength provides sensitivity to forest structure and above-ground biomass [6], [7]. Since radiometric measurements contribute directly to above-ground biomass estimation [8], [9], radiometric errors can propagate into the retrieved biomass estimates. Radio-frequency interference (RFI) can further compromise image radiometry, as can the techniques used to mitigate it. These techniques typically suppress interference in the frequency domain, either before or after image focusing [10]. Unless properly implemented, such processing can also alter the amplitude of the desired SAR signal, introducing radiometric distortions into the resulting images.

Conventional calibration strategies typically rely on a com-

While these approaches provide high accuracy during the commissioning phase, their long-term availability and global coverage are inherently limited. At P-band, in fact, implementing conventional external calibration infrastructure becomes particularly challenging. The long wavelength implies that corner reflectors must be physically very large to ensure sufficient radar cross section, making their design, deployment, and maintenance both complex and costly [12]. Similarly, active transponders operating at P-band require specialized hardware, high power, and careful design, which significantly limits their practical use [13]. As a consequence, unlike higher-frequency missions, there is currently no global network of well-characterized P-band calibration targets available [14]. This lack of dedicated infrastructure severely constrains the applicability of traditional calibration strategies, especially beyond the commissioning phase. Moreover, the sparse spatial distribution of any potential calibrators would prevent consistent monitoring of radiometric stability at a global scale. In this context, relying solely on external references becomes unsustainable for long-term mission operations. Therefore, alternative approaches that do not depend on artificial targets are required. An alternative and complementary solution is to exploit naturally occurring stable targets in the scene, commonly referred to as permanent scatterers (PSs, [15]), whose amplitude stability can be leveraged to monitor temporal variations in the system gain [16].

PS-based calibration techniques have been extensively investigated for C- and X-band SAR missions, for which long time series comprising several tens of acquisitions are often available [17]. Under these conditions, a large number of independent observations (typically more than 30) improves estimation accuracy and can allow performance to approach asymptotic bounds. In contrast, BIOMASS provides a limited number of repeat-pass acquisitions over a given area, with typical tomographic stacks comprising only Ni = 7 images. Combining two stacks covering the same area increases the number of observations and may therefore improve calibration accuracy. However, differences in mean incidence angle and limited footprint overlap restrict the set of PSs that can be consistently identified across both stacks. Suitable PSs must lie within the overlapping area and exhibit a sufficiently stable backscattering response over the incidence angles spanned by the two stacks.

The rest of the paper is organized as follows: Section II presents the PS detection and radiometric gain estimation framework and evaluates its performance through simulations. Section III applies the method to BIOMASS datasets acquired over Nairobi and Córdoba and provides a qualitative comparison with BIOMASS Calibration Transponder measurements. Section IV summarizes the main findings. The appendices discuss the bias in the estimated dispersion index and its relationship with the signal-to-noise ratio.

#II. PS DETECTION, PARAMETER ESTIMATION AND SIMULATED PERFORMANCES

p. 2In this section, we briefly recap the theory underlying PSs and the estimation of radiometric gains using them. A more detailed analysis is carried out in [15]–[19].

#A. Signal model

Let us consider Ni images and Np persistent scatterers (PSs) in the scene. The complex observation of the pth target in the nth image is modeled as [16]:

\[y _ { n } ^ { p } = a _ { n } \left ( b _ { p } e ^ { j \phi _ { n } ^ { p } } + w _ { n } ^ { p } \right ) ,\](1)

where an > 0 is the amplitude gain of the nth image, bp ≥ 0 is the amplitude of the pth PS, ϕpn is its phase, and wpn represents additive clutter and thermal noise before multiplication by the image gain. The image gains may vary between acquisitions but are assumed to be spatially uniform over the analyzed scene. Conversely, the PS amplitudes may differ between targets but are assumed to remain constant across acquisitions. This complementary dependence on the image and target indices allows the image gains and PS amplitudes to be separated up to a common multiplicative factor. We resolve this ambiguity by setting a1 = 1, so that the estimated gains are relative to the first image and the PS amplitudes are expressed on its amplitude scale. The observation model in (1) can be written in vector form as

\[\mathbf {y} = \mathbf {x} + \mathbf {w} _ {a},\](2)

where y ∈ CNt , with Nt = NpNi, contains the observations stacked target by target, with the image index varying fastest:

\[y = \left [ y _ { 1 } ^ { 1 } \, \cdots \, y _ { N _ { i } } ^ { 1 } y _ { 1 } ^ { 2 } \, \cdots \, y _ { N _ { i } } ^ { 2 } \cdots y _ { 1 } ^ { N _ { p } } \, \cdots \, y _ { N _ { i } } ^ { N _ { p } } \right ] ^ { T } .\](3)

Using the same ordering for all stacked quantities, we define

\[x = ( b \otimes a ) \circ \phi ,\](4)
\[b = [ b _ { 1 } \, \cdots \, b _ { N _ { p } } ] ^ { T } ,\](5)
\[a = [ 1 \ a _ { 2 } \ \cdots \ a _ { N _ { i } } ] ^ { T } ,\](6)
\[\left[ \phi \right] _ {(p - 1) N _ {\mathrm{i}} + n} = e ^ {j \phi_ {n} ^ {p}},\](7)
\[\left[ \mathbf {w} _ {a} \right] _ {(p - 1) N _ {\mathrm{i}} + n} = a _ {n} w _ {n} ^ {p}.\](8)

Here, ⊗ denotes the Kronecker product, ◦ denotes the Hadamard product, and the superscript T denotes transposition. Our objective is to estimate the relative image gains a, together with the nuisance parameters b and ϕ and the parameters describing the noise power.

#B. Incoherent detection

The first step in the processing pipeline is PS detection. Incoherent detection discards phase information and relies on image amplitudes. In particular, [16] showed that the dispersion index (DI) provides a figure of merit equivalent to that of the generalized likelihood ratio test (GLRT):

\[D I = \frac { \mu } { \sigma }\](9)

p. 3where µ and σ are the temporal mean and standard deviation of the amplitude of each pixel, respectively. A target exhibiting high reflectivity and small temporal fluctuations is therefore a suitable PS candidate. A transformation of DI was proposed in [16] to obtain a figure of merit ranging from 0 to 1. Here, we refer to this quantity as the normalized dispersion index (NDI):

\[\ N D I = \frac { 1 } { \sqrt { 1 + \frac { 1 } { D I ^ { 2 } } } }\](10)

which approaches 1 as DI tends to infinity and 0 as DI tends to zero. When only a few images are available, the DI estimate is biased. This bias is directly proportional to the true dispersion index and inversely proportional to the number of images in the stack:

\[\mathbb { E } [ \hat { D } I ] \approx \frac { \mu } { \sigma } + \underbrace { \frac { \mu } { 2 N \sigma } } _ { b i a s }\](11)

The derivation of (11) is provided in Appendix A. Figure 1 presents simulation results for Ni = 7, 12, 15, 25, showing that the estimated dispersion index increasingly departs from its nominal value as the stack size decreases, particularly at high nominal DI values. The limited number of acquisitions, combined with the high temporal stability achievable with Pband measurements, motivates the use of a high DI threshold. For example, an estimated DI threshold of 16 for a stack of 7 images leads to the detection of PSs with a true DI of approximately 14.

Coherent PS detection is also possible, but it requires phase estimation. Assuming a structured phase model, such as a linear model, the phase history can be estimated and compensated before applying coherent detection, as described in [16]. Here, however, we favor incoherent detection because it avoids phase estimation, which can be challenging when only a few acquisitions are available. Accordingly, only incoherent detection is considered in the following.

Following [17], we also apply an amplitude threshold. For low-frequency missions such as BIOMASS, distributed scatterers can exhibit high temporal stability as well. Furthermore, the DI bias associated with short stacks motivates an additional selection criterion to reduce false alarms. In the following analysis, we select the brightest 2% of pixels in the scene and compute DI only for this subset.

An alternative approach is to require the backscatter to exceed the instrument’s noise-equivalent sigma zero (NESZ) by at least 10 dB. For BIOMASS, a NESZ of −27 dB yields a backscatter threshold of σ0 > −17 dB.

#C. Detection performances

We simulated a set of PSs across a stack of 12 images, with SNR values ranging from 12 to 20 dB, and evaluated the probability of missed detection (PMD) and the probability of false alarm (PFA) for different NDI thresholds. The stack size was chosen to match the number of single-look complex (SLC) images in the real dataset analyzed in the final section of this contribution. Figure 2 presents the results for the incoherent detector, which relies exclusively on the amplitude information of each PS candidate. Increasing the threshold reduces the probability of incorrectly identifying clutter as a PS, at the cost of a higher probability of missed detection. For example, an NDI threshold of 0.99, corresponding to a DI threshold of approximately 7.02 through DI = NDI/√1-NDI2 , yields a false-alarm probability of approximately 10−5 . At this threshold, the probability of missed detection is approximately 80% for a PS with an SNR of 12 dB and decreases to 0.1% at an SNR of 18 dB.

#D. Incoherent estimation

p. 4The log-likelihood of the observation can be expressed as follows (omitting a constant term that is irrelevant for the maximization):

\[\mathcal { L } ( y | x , C ) = - ( y - x ) ^ { \text {H} } C ^ { - 1 } ( y - x ) - \log | C | \quad ( 1 2 ) \ \ s o { 1 }\](12)

If the PS phases are completely unknown, we can replace in (12) the maximum likelihood solution:

\[\hat { \phi } _ { n } ^ { p } = - \angle y _ { n } ^ { p }\](13)

leading to the expression of the log-likelihood in (14).

\[\mathcal {L} = 2 \sum_ {n = 1} ^ {N _ {\mathrm{i}}} \frac {1}{a _ {n}} \sum_ {p = 1} ^ {N _ {\mathrm{p}}} \frac {b _ {p} | y _ {n} ^ {p} |}{v _ {p}} - \sum_ {n = 1} ^ {N _ {\mathrm{i}}} \sum_ {p = 1} ^ {N _ {\mathrm{p}}} \frac {| y _ {n} ^ {p} | ^ {2}}{a _ {n} ^ {2} v _ {p}} - N _ {\mathrm{i}} \sum_ {p = 1} ^ {N _ {\mathrm{p}}} \left(\frac {b _ {p} ^ {2}}{v _ {p}} - \log v _ {p}\right) - 2 N _ {\mathrm{p}} \sum_ {n = 1} ^ {N _ {\mathrm{i}}} \log a _ {n}\](14)

The estimation procedure is performed iteratively. Starting from an initial set of gains, these values are used to estimate the PS amplitudes and the noise variances. The resulting estimates are then employed to update the gains, and the process is repeated until convergence. At each iteration, the PS amplitudes are estimated via maximum likelihood by setting to zero the derivative of the log-likelihood in (14) with respect to b,

\[\frac { \partial \mathcal { L } ( y | a ^ { k - 1 } , b , v ) } { \partial b } = 0\](15)

which yields

\[\hat { b } _ { p } ^ { k } = \frac { 1 } { N _ { i } } \sum _ { n = 1 } ^ { N _ { i } } \frac { | y _ { n } ^ { p } | } { a _ { n } ^ { k - 1 } } .\](16)

This estimate corresponds to the normalized temporal mean of each PS. The algorithm then estimates the noise power associated with each PS by nullifying the derivative of the log-likelihood with respect to v

\[\frac { \partial \mathcal { L } ( y | \mathbf a ^ { k - 1 } , \mathbf b ^ { k } , \mathbf v ) } { \partial \mathbf v } = 0 ,\](17)

leading to

\[\hat { v } _ { p } ^ { k } = \frac { 1 } { N _ { i } } \sum _ { n = 1 } ^ { N _ { i } } \frac { | y _ { n } ^ { p } | ^ { 2 } } { ( a _ { n } ^ { k - 1 } ) ^ { 2 } } - ( \hat { b } _ { p } ^ { k } ) ^ { 2 }\](18)

Finally, the gains are updated by setting to zero the derivative of the log-likelihood with respect to a

\[\frac { \partial \mathcal { L } ( y | a , b ^ { k } , v ^ { k } ) } { \partial a } = 0 ,\](19)

which results in a second-order equation. The physically meaningful estimate of the gains is obtained by selecting the largest solution of

\[N _ { p } a _ { n } ^ { 2 } + \sum _ { p = 1 } ^ { N _ { p } } \frac { b _ { p } | y _ { n } ^ { p } | } { v _ { p } } a _ { n } - \sum _ { p = 1 } ^ { N _ { p } } \frac { | y _ { n } ^ { p } | ^ { 2 } } { v _ { p } } = 0 .\](20)

The estimated gains are relative quantities and can therefore be recovered only up to an unknown constant multiplicative factor. Resolving this ambiguity requires an additional constraint or an external reference, such as assuming that the residual gains average to unity in linear scale (or zero in the logarithmic domain) over a sufficiently large number of acquisitions, or using an externally calibrated reflector. Nevertheless, as demonstrated in the following section, the estimated gains provide a valuable basis for assessing radiometric stability and may serve as an early warning indicator of hardware or software malfunctions.

#E. Estimation performances

Before evaluating the estimation performance in terms of the standard deviation of the gain estimates, in [16] a derivation of the Cramér–Rao Bound (CRB) of the estimate of the residual gains is presented, resulting in

\[\sigma _ { C R B } ^ { 2 } = \frac { 1 } { 2 N _ { p } \overline { S N R } }\](21)

where Np is the number of PSs and SNR is the average SignalTo-Noise Ratio (SNR) of all the detected PSs. The CRB for the amplitude gain a > 0 is converted to the decibel domain by considering g(a) = 20 log10 a. The CRB transformation rule gives

\[C R B _ { g } = \left ( \frac { 2 0 } { a \ln 1 0 } \right ) ^ { 2 } \sigma _ { C R B } ^ { 2 }\](22)

Leading to the corresponding standard-deviation bound as ≈ 8.6σCRB/a in decibels. For small relative uncertainties, this also approximates the standard deviation of the transformed estimate through first-order error propagation. An equivalent first-order expression is

\[2 0 \log _ { 1 0 } \left ( 1 + \frac { \sigma _ { C R B } } { a } \right ) \simeq \frac { 2 0 } { \ln 1 0 } \frac { \sigma _ { C R B } } { a }\](23)

This metric already provides a preliminary figure of merit for the expected uncertainty. Figure 3 shows how the CRB varies with both the mean SNR and the number of detected PSs, highlighting a clear trade-off between these quantities. In particular, accurate estimation can still be achieved at low SNR if a sufficiently large number of PSs is available, whereas high SNR enables reliable estimates even with fewer PSs. The black curves in Fig.3 represent standard deviations of 0.1, 0.2, and 0.3 dB. For example, reaching a 0.1 dB standard deviation requires roughly 150 PSs at an average SNR of 15 dB, or about 400 PSs when the average SNR is 10 dB.

To properly assess the performance of the coherent and incoherent estimators across different SNRs and numbers of PSs, a simulation campaign was conducted. In particular, Np = 50, 100, 200, 500 PSs were generated with SNRs ranging from 8 dB to 20 dB over a stack of Ni = 12 images. The incoherent estimator was then applied to estimate the residual radiometric gains. Using the ground truth gains imposed on each image, the estimation error was computed as

\[e _ { n } ^ { d B } = \hat { a } _ { n } ^ { d B } - a _ { n } ^ { d B } ,\](24)
\[\sigma _ { a } = \sqrt { \frac { 1 } { N _ { i } } \sum _ { n } \left ( e _ { n } ^ { d B } - \overline { e } ^ { d B } \right ) ^ { 2 } } .\](25)

⚑ p. 5Figure 4 show the estimator performance for Np = 50, 100, 200, respectively. A common behavior observed across all experiments is that the standard deviation of the estimates approaches the CRB at high SNR. As expected, higher SNR values and/or a larger number of PSs result in improved estimation accuracy, ranging from approximately 0.35 dB for Np = 50 at SNR = 8 dB to values close to 0.05 dB for Np = 500 at SNR = 20 dB.

#III. REAL DATA ANALYSIS

To assess PS availability across different scene types and validate the algorithm’s ability to reliably estimate residual gains, we applied the complete procedure to several datasets acquired during the In-Orbit Commissioning Phase (IOCP) and the subsequent tomographic phase. This section presents results from selected test cases, illustrating the method's potential for identifying processing-chain anomalies and assessing the instrument’s long-term radiometric stability.

First, the Level-1A (L1A) images are downloaded from the Multi-Mission Algorithm and Analysis Platform (MAAP). These data are already calibrated, and polarimetric corrections have been applied. The SLC stack is then processed through a two-step coregistration procedure combining geometric alignment with local cross-correlation to ensure accurate registration across all acquisitions. Next, the dispersion index is computed according to Eq. (9) for each polarimetric channel as well as for the span, defined as the image whose pixel amplitude is given by √|V V |2 + |V H|2 + |HV |2 + |HH|2 .

#A. Nairobi - Kenya

During the IOCP, several test sites were analyzed using PSCal, including an area surrounding Nairobi, Kenya. The dataset comprises ten acquisitions separated by three-day intervals, spanning 27 days (Table I). The nominal geometrical baselines were below 1 km, consistent with the acquisition configuration used during the early stages of the IOCP. All images were radiometrically calibrated using the lookup tables (LUTs) provided in the product metadata, such that multilooking the squared magnitude of the calibrated samples yields an estimate of the backscatter coefficient σ0.

Visual inspection of Fig. 5 reveals a pronounced radiometric anomaly in the third acquisition, dated 31 May 2025. An initial assessment can be obtained by comparing image histograms or median amplitudes across the stack. The black markers in Fig. 6 show the median amplitude relative to the first acquisition and indicate a substantial decrease in the third image. However, scene-wide statistics alone cannot distinguish an instrumental or processing anomaly from changes associated with environmental conditions, such as rainfall and soil moisture, or propagation effects, such as ionospheric disturbances.

p. 6PS candidates were identified using the incoherent detector, with a minimum dispersion index of 16, corresponding to an SNR of approximately 21 dB. The minimum backscatter was set for a minimum σ0 of 7 dB. The latter threshold is well above the instrument’s nominal NESZ requirement of −27 dB. These criteria yielded 735 PS candidates in SPAN, 184 in HH, and 334 in VV, whereas no candidates were detected in the cross-polarized channels. The density of PS is 0.5 PS/km2 in the SPAN, 0.21 PS/km2 in the VV and 0.12 PS/km2 in the HH.

The larger number of PS candidates identified using the span may partly result from a reduction in relative temporal dispersion when summing the powers of different polarimetric channels. When their fluctuations are not perfectly positively correlated, the summed power can exhibit a lower relative dispersion than the individual contributions. This reduction becomes more pronounced when fluctuations in different channels partially compensate for one another. Consequently, more pixels may satisfy the dispersion threshold, even in the absence of a single dominant, temporally stable scatterer.

The corresponding residual radiometric gains, estimated using PSCal, are shown in Fig. 6.

The SPAN, HH, and VV estimates exhibit consistent behavior across the stack and identify a decrease of approximately 1 dB between the first and third acquisitions. Conversely, the decreasing trend in median amplitude from the fourth acquisition onward is absent from the PSCal estimates. This difference is consistent with a change in scene backscatter rather than a common radiometric gain variation. By restricting the estimation to appropriately selected stable scatterers, PSCal reduces sensitivity to scene-wide backscatter changes that affect histogram-and median-based assessments. Excluding the anomalous acquisition, the estimated gain variations are generally within 0.1 dB, indicating high relative radiometric stability over the observation period.

Subsequent investigation established that the third acquisition was the only image in the stack processed with radio-frequency interference (RFI) mitigation enabled. A defect in the initial implementation of this processing step distorted the signal spectrum and consequently altered the image radiometry. This case illustrates the value of PSCal as an early indicator of radiometric anomalies and its ability to help distinguish common gain variations from changes in scene backscatter.

#B. Córdoba - Argentina

The second dataset covers Argentina and combines two sub-stacks acquired during different mission phases. The first comprises five IOCP acquisitions, while the second consists of seven acquisitions collected during the tomographic phase. As reported in Table II, both sub-stacks were acquired at three-day intervals, spanning 12 and 18 days, respectively, with an approximately eight-month gap between them. This extended observation period allows assessment of the instrument’s long-term relative radiometric stability.

Combining the two sub-stacks introduces three main challenges. First, the longer observation period may reduce the number of scatterers that remain stable compared with a single, regularly sampled stack covering a shorter period. Second, the different acquisition geometries result in a substantial inter-stack baseline and a corresponding change in incidence angle. Third, the reduced overlap between the acquisition footprints limits the area available for PS detection. Consequently, jointly selected PSs must exhibit stable backscatter both over time and across the sampled viewing geometries. This requirement favors targets with limited angular sensitivity, although it does not imply isotropic scattering.

p. 7Figure 7 shows the mean normal baseline for each of the twelve acquisitions. The first five acquisitions have approximately zero relative baseline, whereas the seven tomographic acquisitions span normal baselines of up to approximately 4 km within their sub-stack. The two sub-stacks are separated by a normal baseline of approximately 40 km.

Visual inspection reveals a change in the temporal evolution of the average scene backscatter beginning on February 17 (Fig. 8). The images become brighter, potentially reflecting changes in the scene, the instrument response, or the processing pipeline. This increase is also evident from the black markers in Fig. 10, which represent the median amplitude of each image normalized to that of the first acquisition in the stack.

The larger number of acquisitions compared with the previous case study supports a more reliable estimation of the DI, allowing a less restrictive selection threshold. PS candidates were identified using the incoherent detector, with a minimum dispersion index of 12.5, corresponding to an SNR of approximately 19 dB, and a minimum σ0 of −17 dB. The latter threshold remains well above the instrument’s nominal NESZ requirement of −27 dB. These criteria yielded 105 PS candidates in SPAN, 21 in HH, and 29 in VV, while no candidates were detected in the cross-polarized channels. The density of PSs in this case is much lower than in the previous case due to scene composition. The density of PSs is 0.1 PS/km2 in the SPAN and roughly 0.03 PS/km2 in the VV and HH. In Figure 9 a zoomed amplitude image with the detection (red dots) of the PSs found. Most of them are man-made objects. The residual radiometric gains estimated using PSCal are shown in Fig. 10.

p. 8The gain estimates exhibit consistent oscillations across the available polarization channels, with variations on the order of 0.1 dB. Moreover, their temporal evolution does not follow the changes in median scene amplitude. These observations suggest that the pronounced scene brightening is not primarily driven by a common instrumental gain variation. In general, the measured amplitude of each pixel depends on both the target response and the radiometric response of the acquisition and processing chain. If scene-induced variations dominate the instrumental fluctuations, selecting sufficiently stable scatterers can suppress the influence of scene variability and enable the estimation of residual radiometric gains. This interpretation assumes that the selected scatterers remain stable throughout the observation period.

#C. Qualitative BIOMASS Calibration Transponder (BCT) comparison

The residual radiometric gains estimated by PSCal over Argentina are compared with the BCT measurements in the HH and VV channels during the overlapping observation period in February 2026. For each polarization, a constant offset, computed as the difference between the means of the two full time series, is subtracted from the BCT measurements to account for their different reference levels.

The comparison is necessarily qualitative, as the two approaches employ different measurement and estimation techniques, observe different sites, and sample different acquisition dates. Neither point-by-point agreement nor identical temporal trends should therefore be expected. Moreover, the offset correction enables a comparison of relative variations but precludes an assessment of agreement in absolute radiometric level. An additional limitation is that the BCT-derived gains do not account for potential fluctuations in the transponder response, which may lead to either an overestimation or an underestimation of the instrument’s radiometric variability. Despite these limitations, both datasets exhibit fluctuations on the order of a few tenths of a decibel. Although the PSCal estimates show larger excursions over the selected interval, their magnitude remains comparable to that of the BCT measurements. This agreement in scale supports the plausibility of the residual radiometric variations retrieved by PSCal, while providing a qualitative consistency check rather than a direct validation of the individual gain estimates.

#IV. CONCLUSION

⚑ p. 9This study investigated the use of permanent scatterers to assess the relative radiometric stability of BIOMASS Pband SAR instrument. The analysis combined amplitude-based PS detection, iterative estimation of residual radiometric gains, and simulations representative of the limited stack sizes available during the mission. The results highlight PS selection as a critical step: with few acquisitions, uncertainty in the estimated dispersion index complicates the identification of stable targets, requiring stringent selection criteria. Simulations further show that gain estimation accuracy improves with both the number of available PSs and their signal-to-noise ratio, approaching the theoretical performance bound at high SNR. The real-data experiments demonstrate the value of PSCal for identifying radiometric anomalies and assessing relative gain variations in the presence of changing scene backscatter. Over Nairobi, the method detected an approximately 1 dB anomaly subsequently attributed to a defect in the RFI mitigation processing, while the remaining acquisitions exhibited estimated gain variations generally within 0.1 dB. Over Córdoba, the joint analysis of two sub-stacks separated by approximately eight months yielded residual gain variations on the order of 0.1 dB, despite substantial differences in acquisition geometry and pronounced changes in median scene amplitude. The qualitative comparison with BIOMASS Calibration Transponder measurements showed fluctuations of comparable magnitude, supporting the plausibility of the PSCal estimates without providing a direct validation.

These findings support the use of PSCal as a complementary tool for monitoring the relative radiometric response of the instrument and processing chain. Its interpretation remains conditional on the temporal and angular stability of the selected scatterers, and the estimated gains do not provide an absolute radiometric reference. Future work should establish an operational criterion for selecting detection thresholds that balances scatterer reliability and estimation uncertainty, extend the assessment to additional sites and acquisition configurations, and pursue closer temporal alignment with independent calibration measurements.

\[D I = \frac { \mu } { \sigma } ,\](26)

and its empirical estimate isˆ

\[N = N _ {I} + j N _ {Q},\](33)

with

\[N _ { I } , N _ { Q } \sim \mathcal { N } ( 0 , \sigma _ { n } ^ { 2 } ) ,\](34)

independent and identically distributed. The total mean noise power is therefore

\[\mathbb { E } \left [ | N | ^ { 2 } \right ] = \mathbb { E } \left [ N _ { I } ^ { 2 } + N _ { Q } ^ { 2 } \right ] = 2 \sigma _ { n } ^ { 2 } .\](35)

Defining the SNR as the ratio between signal power and total complex noise power gives

\[S N R = \frac { A ^ { 2 } } { \mathbb { E } [ | N | ^ { 2 } ] } = \frac { A ^ { 2 } } { 2 \sigma _ { n } ^ { 2 } } .\](36)

p. 10Now consider the incoherent amplitude image,

\[R = | Z | = \sqrt { ( A + N _ { I } ) ^ { 2 } + N _ { Q } ^ { 2 } } .\](37)

The incoherent dispersion index is defined as

\[D = \frac { \mu _ { R } } { \sigma _ { R } } = \frac { \mathbb { E } [ R ] } { \sqrt { V a r ( R ) } } .\](38)

In the high-SNR regime,

\[A \gg \sigma _ { n } ,\](39)

the amplitude R can be expanded a tthe first order around A:

\[R \simeq A + N _ { I } .\](40)

Hence,

\[\mathbb { E } [ R ] \simeq A ,\](41)

and

\[V a r ( R ) \simeq V a r ( N _ { I } ) = \sigma _ { n } ^ { 2 } .\](42)

Thus,

\[D = \frac { \mu _ { R } } { \sigma _ { R } } \simeq \frac { A } { \sigma _ { n } } .\](43)

Comparing this expression with the one for the SNR, we obtain:

\[S N R _ { d B } \simeq 2 0 \log _ { 1 0 } \left ( \frac { \mu _ { R } } { \sigma _ { R } } \right ) - 3 \ d B .\](44)
