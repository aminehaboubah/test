# Test samples

## `18650-clustering-zenodo/` — real, third-party (CC BY 4.0)

Unmodified contents of:

> Olivero Ortiz, V. J.; Oliveros Pantoja, I.; Ripoll Solano, L. A.; Robles Algarín, C.; Mendoza Polo, J. C.
> *Dataset and source code for: PONE-D-26-06286* ("Clustering recovered 18650 lithium-ion cells to
> improve homogeneity in second-life battery pack construction", submitted to PLOS ONE). Zenodo, 2026.
> https://doi.org/10.5281/zenodo.20317410 — licensed CC BY 4.0 (see its `LICENSE`).

92 recovered laptop cells: capacity, voltage, resistance (3 replicates), chemistry; seven Python
scripts; supplementary tables S1–S6. No figures and no manuscript, so it exercises the
"No paper yet" path. Downloaded 2026-11-09 from the record's single zip file.

## `battery-study/` — synthetic, made for testing

Everything here was generated for this repository: the data come from a simulated fade model with
random noise, the figures from the included scripts, and `drafts/draft_v1_ai.md` was written to
imitate a weak AI draft with deliberate errors (62 % / 1000 cycles / 99.99 % / 95.3 % vs. the data's
45.8 % / 500 cycles / 99.91 % / 65.0 %, and a cited SEM "Figure 4" that does not exist).
It is not real research.
